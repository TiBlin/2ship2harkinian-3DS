# Audit MM natif Blinky 07

Périmètre : les 30 fichiers MM précédemment classés F. Chaque base a été comparée octet par octet avec l’archive officielle HarbourMasters au commit `6bfd6a35a0e0d8900273e61ce85cb038d4f4a528`.

Quatre fichiers reviennent exactement à l’amont ; les autres conservent l’amont attribué, avec une adaptation native examinée. Les blocs substantiels de résidence, ordonnanceur audio, index d’alias, sondage de ressource et allocation ont été réimplémentés à partir de leurs contrats MM, C++ et libctru. Les corrections ADPCM/DMEM et la barrière jeu/audio restent conservées.

La consultation du code local antérieur permet de préserver ses contraintes ; cette démarche n’est pas une certification juridique en salle blanche. Aucun code d’implémentation alpha3 n’a été utilisé pour rédiger ces remplacements. Le jeu MM et ses dépendances restent des composants amont attribués, et ne sont pas déclarés originaux Blinky.

Le JSON adjacent contient les SHA-256 avant, après et amont ainsi que les contrats par fichier ; `mm-vs-official.patch` contient chaque delta normalisé.
