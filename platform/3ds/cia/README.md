# 2Ship 3DS application metadata

`app.rsf` keeps the v7 memory and service layout. This experimental port uses
UniqueId `0x25348`, TitleID `0004000002534800` and product code `CTR-P-2SH3`.
The identifier differs from the supplied SoH build; it is a local homebrew
choice, not a registered allocation.

`icon.png`, `banner.png`, `icon.icn` and `banner.bnr` were generated by
`scripts/package_3ds.py`. The art consists of original geometric text and
rectangles; the banner audio is silence. No Zelda or SoH images are used.
The procedural artwork is provided under CC0-1.0.

To regenerate those assets in a scratch directory:

```text
python scripts/package_3ds.py --artwork-only --output work/artwork --devkitpro C:/devkitPro
```

Full packaging always generates fresh artwork from the code and embeds only
a readme in RomFS. The game archives must be supplied separately in
`sdmc:/3ds/2ship/`.
